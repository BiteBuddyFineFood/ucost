# 数据交换格式 v2

日期：2026-11-12。实现：`src/server/exchange-codec.ts`、`src/server/exchange.ts`。入口：设置 → 导入与导出。

## JSON 完整业务交换

根字段：`schemaVersion: 2`、`datasetId`（当前用户独立稳定来源 ID）、`exportedAt`、`currency: "CNY"`、`amountUnit: "cent"`、`attachmentPolicy: "metadata-only"`。

数据数组：`accounts`、`categories`、`rules`、`lists`、`groups`、`shopping`、`ledger`、`items`、`usage`、`settlements`、`savings`、`drafts`、`attachments`、`reviews`、`votes`、`analyses`。记录 `id` 为源实体稳定 ID，金额一律 JSON 整数分；可空预算的 null 与零不同。JSON 始终导出全部正式记录，包括待核对/撤销/主动停用/被结算替代的省钱；不写任何汇总行。

导出不包含 ownerId、密码、登录会话、AI 配置/密钥/额度/执行任务、分享 token、附件 storageKey。结算成员内去掉 ownerId；投票者 ID 为不可用于登录的匿名标识。用户设置和默认账户不写回目标用户，避免合并导入覆盖当地偏好；历史账单账户为空时保持空。

`deletedSources: [{entity, sourceId}]` 是已删除清单/购物项/草稿/账单的历史来源说明。导入以当前用户和源数据集隔离的 `deleted:...` 标识保存，保留“来源已删除”的组和原始来源关系，不重建被删记录。它不能替代退款原单、有效账单/购物双向关联、有效结算成员或账户/分类。普通缺失引用不会自动变成历史删除。

附件只导出元数据。导入后 `missing=true`，界面显示“附件未迁移”，私有附件接口拒绝读取；不恢复本机其他路径。需要图片时用匹配数据库与 uploads 的完整备份。导入评议一律撤销，保留内容和匿名历史投票，不产生可用公开链接。

执行中的草稿恢复 pending，清除租约；其他候选及 appliedIndexes 保留并校验。候选内的分类、账户、清单等 ID 及结算成员内的 ID 同时重映射。已经确认的索引必须能对应正式记录。导入不发起 AI 请求，不消耗额度，不重复派生自动省钱。

## CSV v2

模板（含一条可替换示例）：

- `public/templates/ledger-v2.csv`
- `public/templates/savings-v2.csv`

所有行前六列固定：`schemaVersion,datasetId,entity,currency,amountUnit,textEncoding`，值依次为 `2`、固定来源数据集 ID、`ledger`/`savings`、`CNY`、`cent`、`apostrophe-v2`。同一文件这些列必须一致；一行就是一条正式记录，不能加入合计行。可选引用留空，无账户记录不套默认账户。ID 列支持后续 JSON/CSV 共用来源映射；名称列供人工核对，不靠名字自动合并。

账本列：

| 字段 | 含义 |
| --- | --- |
| id,date,type,title,amount | 源记录 ID、YYYY-MM-DD、expense/income/transfer/refund、标题、实付整数分 |
| accountId,accountName,toAccountId,toAccountName | 原账户/转入账户的源 ID 与核对名称；转账必须两账户不同 |
| categoryId,categoryName,groupId,groupName | 分类及展示组的源 ID 与名称；空分类/空组保留 |
| sourceListId,sourceShoppingItemId,refundOfId | 来源清单核对列、实际购物来源 ID、退款原单 ID；清单归属从购物来源恢复，不靠名称 |
| discount,grossAmount,discountDetails | 优惠整数分、优惠前整数分（可空）、优惠解释 |
| autoSaving,orderKey,note | 原自动省钱开关 true/false、订单源标识、备注；导入不会自动生成省钱 |

省钱本列：

| 字段 | 含义 |
| --- | --- |
| id,date,title,type,source | 源 ID、日期、标题、discount/skipped/downgrade/reduced/budget_surplus、manual/ai/automatic/shopping/settlement |
| planned,actual,amount | 计划、实际（前两者可空）、省下金额，均为整数分 |
| groupId,groupName | 展示组 ID 与核对名称 |
| sourceListId,settlementId,ledgerId,shoppingItemId | 来源清单、结算、账单、购物项源 ID |
| status,suppressed,supersededBySettlementId | valid/pending/revoked；用户主动停用 true/false；被哪个结算替代 |
| sourceKey,note | 派生来源唯一键及备注；导入会按本地映射改写来源键以支持后续修改/去重 |

CSV 不携带分类图标、清单预算、完整结算成员和草稿。带复杂关系的 CSV 需要先导入包含来源的 JSON，或显式映射已有实体；无法解决时禁止确认。可以先导入账本 CSV，再导入同一 datasetId 的省钱 CSV，复用账单身份映射；账本 CSV 不自行派生优惠，因此不会叠加两份省钱。CSV 不宣称能单独恢复完整应用。

### 编码和转义

UTF-8 BOM、CRLF 记录换行、双引号包围每个字段、内部双引号加倍，字段内逗号和换行保持原文。

`apostrophe-v2`：原文以 `= + - @ ' Tab CR LF 空格` 任一字符开头时，导出增加一个前导单引号；读取带该标识的 v2 时恰好移除这一个前缀。原有单引号也会先转义，因此往返可逆。不要手工删改机器导出中的前缀。金额列只接受十进制整数分，布尔列只接受 true/false。

## 兼容旧格式

- JSON v1：必须填写固定“旧格式来源标识”。同一旧库后续导出沿用该值；跨库使用不同值。默认图标 tag、未分组、清单预算空、按商品核算。按有效支出回填购买快照与分类，按真实 listId 建组；未知购买和异常多重链接保留待核对，绝不拿预算当实付或新增支出。
- 旧 CSV：识别 `ID,日期,类型,标题,金额（分）,优惠（分）,备注`。缺失分类/账户/组保持空。没有 ID 时按固定来源标识+行号识别，必须保持行顺序；旧 CSV 的单引号防公式前缀无法区分原文，保留并显示降级说明。非标准列名先转换为模板，不猜字段映射。
- 缺失退款原单、跨用户映射、有效结算成员缺失、重复自动来源键等阻止整个任务。可以重新提供完整文件或选择已有目标再预检。

## 预检、冲突与事务

`POST /api/import/preview`：`{content, sourceId?, mappings?: [{entity,sourceId,localId}], decisions?: [{entity,sourceId,choice:"keep"|"new"}]}`。

返回服务端保存的 jobId、30 分钟有效期、记录数、导入前后财务摘要、重复/冲突/待映射/错误和警告。相似标题+金额只提示；按 `ownerId+datasetId+entity+sourceId` 去重。源内容变化或本地导入记录被修改均视作冲突。同名分类受唯一约束，必须显式映射；同名账户、清单、组默认新增，不静默合并。“作为新记录”也要重新验证所有唯一约束及来源图，不能通过它复制有效自动省钱或结算。

`POST /api/import/commit`：仅传 `{jobId}`。提交读取服务端预检文件，不信任客户端修改的摘要；重新检查本地数据和身份映射指纹，变化后要求重新预检。整个任务一个事务，记录创建、双向关联、来源映射及成功报告共同提交。重试同一 jobId 返回保存结果；重复文件跳过；并发任务只有通过当前状态校验的任务可新增。

限制为 8MB 文件、10000 条记录（含兼容回填后的组），SQLite 短写事务重试使用现有封装。只在预检中明确映射/去重，不覆盖已有业务记录。大文件需拆分，不能把单个 CSV 拆断退款和必要来源后绕过校验。完整业务迁移优先使用 JSON。

导出接口：`GET /api/export` 返回完整 JSON；`?format=csv&entity=ledger|savings&scope=all` 返回全部 CSV；`scope=filtered` 才应用 `start,end,type,categoryId,accountId,groupId`，后三者可用 none 选择未指定。设置页可直接选择筛选条件，JSON 不受这些筛选影响。

账本和省钱本工具栏还提供“导出当前筛选 CSV”，使用该页面实际日期、类型、分类/来源、账户（含转入账户）、搜索和撤销显示条件；查看全组时导出全组成员。与分组/平铺和分页无关，始终每条正式记录一行。设置页筛选提供独立的导出条件。
